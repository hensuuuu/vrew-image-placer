# Vrew 이미지 자동 배치

장면 번호에 맞춰 이미지를 Vrew 프로젝트(`.vrew`)에 자동으로 깔아 주는 도구입니다.

Vrew에서 이미지를 한 장씩 구간 잡아 끼우고 애니메이션을 고르는 반복 작업을 대신합니다.
브라우저에서 열어 폴더만 넣으면 몇 초 만에 끝납니다.

## 바로 쓰기

### https://hensuuuu.github.io/vrew-image-placer/

주소만 열면 됩니다. 즐겨찾기에 넣어 두고 쓰세요.
파일은 브라우저 안에서만 처리되고 어디로도 올라가지 않습니다.

내려받아 쓰려면 [`index.html`](index.html) 하나만 저장해 더블클릭해도 똑같이 동작합니다. (인터넷 없이도 됩니다)

## 쓰는 법

1. 위 주소를 엽니다.
2. 작업할 폴더를 끌어다 놓거나 `[폴더 선택하기]`를 누릅니다.
3. 점검 결과를 확인하고 `[시작하기]`.
4. 다운로드 폴더에 `..._이미지배치.vrew`가 저장됩니다. Vrew에서 열면 됩니다.

원본 파일은 건드리지 않고 새 파일로 저장합니다.

### 폴더에 있어야 하는 것

| | 예시 | 설명 |
|---|---|---|
| Vrew 파일 | `프로젝트.vrew` | Vrew에서 TTS까지 만든 뒤 저장한 것. 이미지는 없어도 됩니다 |
| 장면 목록 | `*_flow_prompts.txt` | 이미지를 만들 때 쓴 파일 |
| 이미지 | `001-1.jpeg`, `002-2.jpeg` … | 앞 세 자리가 장면 번호 |

이미지는 하위 폴더에 있어도 됩니다.

## 특징

- **설치할 것 없음** — HTML 파일 하나. 서버도, 인터넷도 필요 없습니다
- **파일이 밖으로 안 나감** — 전부 브라우저 안에서 처리합니다. 200MB짜리를 업로드할 필요가 없습니다
- **Windows / macOS 동일** — 크롬, 엣지에서 동작합니다
- **미리 점검** — 시작하기 전에 위험 요소를 찾아 보여 주고, 치명적인 문제가 있으면 버튼을 잠급니다

## 어떻게 배치하나

1. 이미지 파일명 앞자리(`001`)를 장면 번호로 읽습니다.
2. 장면 목록에서 그 번호의 문장을 찾아, `.vrew` 자막에서 같은 문장이 시작되는 지점을 찾습니다.
3. 그 지점부터 다음 장면이 시작되기 직전까지를 한 이미지가 채웁니다.
4. 마지막 이미지는 영상 끝까지 이어집니다.

자막은 문장 단위가 아니라 호흡 단위로 잘려 있어 한 자막에 두 문장이 섞이기도 합니다.
그래서 전체 자막을 하나로 이어 붙여 위치를 찾은 뒤 자막 번호를 역산합니다.

이야기가 시작되기 전 도입부(후킹)에는 이미지를 깔지 않습니다. 보통 따로 만든 영상이 들어가는 자리입니다.

### 화면 연출

모든 이미지는 여백이 남지 않는 `채우기(cut)` 방식이고, 켄번스 효과 6종을 순서대로 돌려 씁니다.

```
zoom-in → zoom-out → left-to-right → right-to-left → top-to-bottom → bottom-to-top
```

## 정확도

사람이 직접 배치한 완성본과 대조해 검증했습니다.

| 프로젝트 | 자막 수 | 결과 |
|---|---|---|
| 시집살이 삼 년 만의 첫 친정길 | 2,987 | 40개 구간 **전부 일치** |
| 암행어사 되어 집에 왔더니 | 1,832 | 40/40 배치, 빈 구간 없음 |

이미지 좌표 계산식은 실제 Vrew 출력값과 소수점 12자리까지 일치합니다.

## 파일 구성

```
index.html          받아서 바로 쓰는 파일 (src/를 하나로 합친 것)
src/
  index.html        화면
  vrewcore.js       배치 로직
  vrewzip.js        .vrew(ZIP) 읽기·쓰기
tools/
  vrew_build.py     같은 기능의 파이썬 판. 여러 폴더를 한 번에 처리할 때
build.py            src/ → index.html 합치기
```

`src/`를 고친 뒤에는 이렇게 다시 합칩니다.

```bash
python build.py
```

### 파이썬 판

```python
import vrew_build

vrew_build.run(
    base="프로젝트 폴더",
    vrew_name="원본.vrew",
    prompts_name="장면목록_flow_prompts.txt",
    image_dir="이미지 폴더",
    out_name="결과.vrew",
    variant=1,          # 001-1 / 001-2 중 선택. None이면 첫 번째
    cover_intro=False,  # True면 도입부까지 첫 이미지로 채움
)
```

표준 라이브러리만 씁니다. 설치할 패키지가 없습니다.

## 기술 메모

`.vrew`는 ZIP이고 안에 `project.json`과 미디어 파일이 들어 있습니다.
항목이 전부 무압축(STORED)이라 압축 코드 없이 바이트만 옮기면 됩니다. 그래서 외부 라이브러리가 하나도 필요 없습니다.

이미지는 이렇게 연결됩니다.

```
clip.assetIds[] → props.assets[id].trackIds[] → props.tracks[id]
```

한 이미지를 여러 자막에 걸치려면 트랙을 복제하는 게 아니라
**같은 `assetId`를 그 구간 모든 자막의 `assetIds`에 넣습니다.**

`project.json` 스키마 버전 16, 17에서 확인했습니다.

## 제한

- 목소리(TTS)는 만들지 못합니다. Vrew에서 만들어 저장한 뒤 사용하세요
- 자막을 많이 고쳤다면 장면을 못 찾을 수 있습니다 (그 경우 점검 화면에서 알려 줍니다)
- 브라우저에서 큰 파일을 다루므로 메모리를 넉넉히 씁니다
